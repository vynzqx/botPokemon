# botPokemon

***Pokémon Bot - Automated Pokémon Training System***
*Nama Repositori*: <ins>Pokemon-Bot-Automation</ins>
*Deskripsi*: Sistem bot otomatis untuk melatih, memberi makan, dan mempertarungkan Pokémon 
menggunakan Python asinkron dan PokeAPI. Bot ini mensimulasikan perilaku trainer Pokémon 
dengan kemampuan battle otomatis, sistem feeding, dan manajemen Pokémon.

**Fitur Utama**:
  - Auto battle dengan perhitungan damage dan type effectiveness
  - Sistem feeding dan healing Pokémon
  - Integrasi dengan PokeAPI untuk data Pokémon real-time
  - Multi-class Pokémon (Wizard, Fighter) dengan ability khusus
  - Manajemen status Pokémon (HP, power, level, experience)

*Teknologi*: 
  *Python
  *aiohttp
  *asyncio
  *PokeAPI
